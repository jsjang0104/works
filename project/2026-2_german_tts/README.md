# German TTS

- 한국외대 독일어과의 전공필수 과목 [독일어읽기B2](https://wis.hufs.ac.kr/src08/jsp/lecture/syllabus.jsp?mode=print&ledg_year=2026&ledg_sessn=3&org_sect=A&lssn_cd=A03202802)의 중간고사, 기말고사는 보통 한국식 내신식으로 출제된다.

- 따라서 중간, 기말고사에서 좋은 성적을 받기 위해서는 본문 암기가 중요한데, 이에 시간을 내어 따로 암기한다면 정확도가 매우 낮아지고 쓰이는 cost도 만만치 않을 것이다.

- 이 프로젝트의 목적은 off-the-shelf 모델들을 이용하여 1) 먼저 교재의 텍스트를 OCR로 추출하고 2) 해당 텍스트들을 TTS 모델을 이용하여 독일어 음성 파일로 변환하는 시스템을 개발하는 것이다. 

- 이렇게 만들어진 음성 파일을 시도때도 없이 들어서 효율적으로 암기할 수 있도록 한다.

- 다만 주의할 점은, 독일어 교재에 저작권이 있어 깃허브에 함부로 올리면 안되기 때문에 end-to-end 시스템만 깃허브에 공개하며 나온 모든 결과물은 업로드하지 않는다.
