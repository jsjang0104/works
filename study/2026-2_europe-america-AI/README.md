# 유럽-아메리카 multilingual AI 텍스트 분석과 적용

[Syllabus](https://wis.hufs.ac.kr/src08/jsp/lecture/syllabus.jsp?mode=print&ledg_year=2026&ledg_sessn=3&org_sect=A&lssn_cd=Q05006101) 

## 중간고사

- 4~7주 실습 결과와 언어 간 비교를 정리 
- 기말 프로젝트 분석 방향과 후반부 분석 대상(텍스트 장르 및 코퍼스)을 확정

## 기말고사

- 학생의 역할: 전공 언어권 콘텐츠를 한국 시장에 도입할지 결정하는 담당자. 전공 언어 문화를 아는 사람은 오직 본인.

- 과정
    1. 코퍼스 분석으로 시장 비교: 전공 언어권 vs 한국- 같은 주제 텍스트를 AI로 분석하여 취향, 담론 차이 파악
    2. 도입 후보 선별 (학생 판단): 분석 결과를 바탕으로 한국 시장에 맞을 것 같은 콘텐츠를 직접 선별하고 이유 제시
    3. 번역 텍스트 생성: 선별한 콘텐츠의 소개 텍스트(200-400단어)를 AI로 한국어 번역
    4. 번역 품질 평가: AI로 생성된 번역을 평가. 원문 맥락이 살아있는가? 무엇이 사라졌는가? 

- 프로젝트 최종 구성: 분석 결과 + 30건 규모 코퍼스 분석 + 언어 간 비교 해석 + AI 오류 비판적 검토 + 개선 예시 제시 + 결론
