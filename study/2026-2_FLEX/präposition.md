# Präposition

## 2격 Genetiv

| 전치사 | 뜻 | 예시 |
| --- | --- | --- |
| wegen | ~때문에 | wegen des Regens (비 때문에) |
| während | ~동안 | während des Unterrichts (수업 동안) |
| trotz | ~에도 불구하고 | trotz des schlechten Wetters (나쁜 날씨에도 불구하고) |
| statt / anstatt | ~대신에 | statt eines Briefes (편지 대신에) |
| innerhalb | ~안에, ~이내에 | innerhalb eines Monats (한 달 이내에) |
| außerhalb | ~밖에 | außerhalb der Stadt (도시 밖에) |
| oberhalb | ~보다 위에 | oberhalb des Dorfes (마을보다 위쪽에) |
| unterhalb | ~보다 아래에 | unterhalb der Brücke (다리보다 아래쪽에) |
| diesseits | ~의 이쪽에 | diesseits der Grenze (국경 이쪽에) |
| jenseits | ~의 저쪽에 | jenseits des Flusses (강 건너편에) |
| aufgrund | ~을 근거로, ~때문에 | aufgrund eines Fehlers (오류 때문에) |
| infolge | ~의 결과로, ~때문에 | infolge eines Unfalls (사고의 결과로) |
| angesichts | ~을 고려하면, ~에 직면하여 | angesichts der Schwierigkeiten (어려움을 고려하면) |
| anhand | ~을 바탕으로, ~을 이용하여 | anhand eines Beispiels (예시를 이용하여) |

- 남성·중성 단수 명사는 2격에서 보통 **-(e)s**가 붙는 것 기억하기: `der Regen → des Regens`, `das Wetter → des Wetters`.

## 3격 Dativ

`아주 바쁜 개미자나`

| 전치사 | 뜻 | 예시 |
| --- | --- | --- |
| aus | ~에서 밖으로, ~출신의, ~로 만들어진 | aus dem Haus (집 안에서 밖으로), aus Holz (나무로 만들어진) |
| zu | ~에게로, ~로 | zu einer Freundin (여자 친구 한 명에게로) |
| bei | ~의 곁에, ~의 집에, ~할 때 | bei meiner Freundin (내 여자 친구의 집에) |
| von | ~로부터, ~의 | von meinem Vater (내 아버지로부터) |
| gegenüber | ~의 맞은편에, ~에 대하여 | gegenüber dem Bahnhof (역 맞은편에) |
| mit | ~와 함께, ~을 이용하여 | mit dem Bus (버스를 타고) |
| seit | ~이래로, ~전부터 지금까지 | seit einem Jahr (1년 전부터 지금까지) |
| nach | ~로, ~후에, ~에 따르면 | nach Berlin (베를린으로), nach dem Essen (식사 후에) |

- 기본 암기: **aus, außer, bei, mit, nach, seit, von, zu**.
- 3격 복수 명사에는 보통 **-n**이 붙는다. 이미 `-n`으로 끝나거나 복수형이 `-s`로 끝나면 추가하지 않는다: `mit den Kindern`, `mit den Frauen`, `mit den Autos`.


## 4격 Akkusativ

`걘 비온 뒤엔 피움`

| 전치사 | 뜻 | 예시 |
| --- | --- | --- |
| gegen | ~에 반대하여, ~에 맞서, ~쯤 | gegen den Plan (계획에 반대하여), gegen acht Uhr (8시쯤) |
| bis | ~까지 | bis nächsten Montag (다음 월요일까지) |
| ohne | ~없이 | ohne einen Regenschirm (우산 없이) |
| durch | ~을 통하여, ~에 의하여 | durch den Park (공원을 통과하여) |
| entlang | ~을 따라 | den Fluss entlang (강을 따라) |
| für | ~을 위해, ~에 찬성하여, ~동안 | für meinen Bruder (내 형제를 위해), für eine Woche (일주일 동안) |
| um | ~주위에, ~시에, ~만큼 | um den Tisch (탁자 주위에), um acht Uhr (8시에) |

- `bis`는 관사 없는 지명·시간 표현과 자주 쓰인다: `bis Berlin`, `bis morgen`. 다른 전치사와 결합하면 **그 전치사가 뒤 명사의 격을 결정**한다: `bis zum Bahnhof`는 `zu + 3격`, `bis in die Stadt`는 `in + 4격`이다.
- `entlang`은 **명사 뒤에 놓이면 4격**이다. 명사 앞에서는 주로 2격을 쓴다: `entlang des Flusses`.

## 3,4격 Wechselpräpositionen

`안아힌인 네운 위포츠`

| 전치사 | 뜻 | 3격: 위치 — Wo? | 4격: 목적지 — Wohin? |
| --- | --- | --- | --- |
| an | ~의 면에 접하여, ~가에 | an der Wand (벽에 붙어) | an die Wand (벽에 붙도록) |
| auf | ~위에 접하여 | auf dem Tisch (탁자 위에) | auf den Tisch (탁자 위로) |
| hinter | ~뒤에 | hinter dem Haus (집 뒤에) | hinter das Haus (집 뒤로) |
| in | ~안에 | in dem Zimmer / im Zimmer (방 안에) | in das Zimmer / ins Zimmer (방 안으로) |
| neben | ~옆에 | neben dem Bett (침대 옆에) | neben das Bett (침대 옆으로) |
| unter | ~아래에 | unter dem Tisch (탁자 아래에) | unter den Tisch (탁자 아래로) |
| über | ~위에, ~을 넘어 | über dem Tisch (탁자 위쪽에) | über den Tisch (탁자 위쪽으로) |
| vor | ~앞에 | vor dem Haus (집 앞에) | vor das Haus (집 앞으로) |
| zwischen | ~사이에 | zwischen den Stühlen (의자들 사이에) | zwischen die Stühle (의자들 사이로) |

- 3격: 움직임, 변화 X 
- 4격: 움직임, 변화 O (슉슈슉 4격) `Ich lege das Buch auf den Tisch.` (나는 책을 탁자 위에 놓는다.)
- **움직임이 있어도 같은 장소 안에서 이루어지면 3격**이다: `Ich laufe im Park.` (나는 공원 안에서 달린다.) / `Ich laufe in den Park.` (나는 공원 안으로 달려 들어간다.)
