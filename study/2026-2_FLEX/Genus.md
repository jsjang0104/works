# Genus

자주 쓰이는 **접미사와 의미별 성 구분 규칙**을 정리한다. 의미에 따른 분류는 예외가 있으므로, 명사는 관사와 함께 외운다.

## 남성명사 (der)

| 기준 | 예시 |
| --- | --- |
| 남성을 나타내는 사람·직업명 | der Vater (아버지), der Lehrer (남자 교사), der Arzt (남자 의사) |
| 직업·행위자를 나타내는 **-er** | der Lehrer (교사), der Arbeiter (노동자) |
| 사람을 나타내는 **-ant, -ent, -ist** | der Praktikant (실습생), der Student (대학생), der Journalist (기자) |
| 외래어 접미사 **-ismus** | der Tourismus (관광), der Kapitalismus (자본주의) |
| **-ling** | der Lehrling (견습생), der Schmetterling (나비) |
| 요일·월·계절 이름은 대체로 남성 | der Montag (월요일), der Januar (1월), der Sommer (여름) |
| 방위 | der Norden (북쪽), der Süden (남쪽), der Osten (동쪽), der Westen (서쪽) |

- 예외: 계절 표현 중 `das Frühjahr` (봄)은 중성이다.

## 여성명사 (die)

| 기준 | 예시 |
| --- | --- |
| **-ung** | die Zeitung (신문), die Meinung (의견) |
| **-heit, -keit** | die Freiheit (자유), die Möglichkeit (가능성) |
| **-schaft** | die Freundschaft (우정), die Gesellschaft (사회) |
| **-ei** | die Bäckerei (빵집), die Bücherei (도서관) |
| **-tion, -sion** | die Information (정보), die Diskussion (토론) |
| **-tät** | die Universität (대학교), die Qualität (품질) |

- 참고: 접미사 규칙은 실제로 해당 접미사가 붙은 단어에 적용한다. `der Sprung` (도약)은 철자만 `-ung`으로 끝나므로 여성명사가 아니다.

## 중성명사 (das)

| 기준 | 예시 |
| --- | --- |
| 축소·애칭을 만드는 **-chen, -lein** | das Mädchen (소녀), das Brötchen (작은 빵), das Büchlein (작은 책) |
| 외래어 접미사 **-ment** | das Dokument (문서), das Instrument (도구·악기), das Experiment (실험) |
| 외래어 접미사 **-um** | das Museum (박물관), das Zentrum (중심), das Studium (대학 공부) |
| 동사 원형의 명사화 | das Essen (먹기·음식), das Lesen (읽기), das Lernen (학습) |
