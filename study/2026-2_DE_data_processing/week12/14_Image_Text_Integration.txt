이미지-텍스트 통합 프롬프트

1. 개념

이미지와 텍스트 지시문을 함께 입력하여 이미지의 내용 분석, 비교, 설명, 추론을 수행하는 방식
사진, 도표, 문서 이미지, 스크린샷 분석에 활용됨
이미지 자체만이 아니라 분석 목적을 명확히 제시해야 함

2. 실제 테스트 플랫폼

ChatGPT (이미지 업로드 기능)

3. 초보적인 프롬프트

[독일어 광고 포스터 이미지 첨부]

이 이미지가 무엇을 보여주는지 설명해줘.

4. 전문적인 프롬프트

[독일어 광고 포스터 이미지 첨부]

당신은 독일 문화와 미디어 분석 전문가이다. 첨부된 광고 포스터를 분석하라.

다음 항목을 순서대로 제시하라.
1. 이미지에 나타난 주요 인물, 사물, 색채, 배치
2. 포스터에 포함된 독일어 문구의 전사와 한국어 번역
3. 예상되는 표적 수용자
4. 시각적 설득 전략
5. 독일 문화적 맥락에서 해석 가능한 요소
6. 이미지에서 명확히 확인할 수 없는 부분

추측과 이미지에서 직접 확인되는 사실을 구분하여 작성하라.

5. 비교 분석

초보 프롬프트는 이미지의 표면적 묘사에 머물 수 있음
전문 프롬프트는 시각 요소, 언어 요소, 문화적 해석을 구조적으로 결합함
이미지-텍스트 통합 프롬프트에서는 관찰과 해석의 구분이 중요함
