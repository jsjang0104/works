ReAct (Reason + Act)

1. 개념

AI가 문제를 분석하는 과정과 외부 정보·도구를 활용하는 행동을 결합하는 방식
일반적으로 추론(Reason) → 행동(Act) → 관찰(Observe) 의 순환 구조를 가짐
최신 정보 조사, 데이터 처리, 복합 업무 자동화에 효과적임

2. 실제 테스트 플랫폼

ChatGPT

3. 초보적인 프롬프트

독일의 최신 대학 등록금 정책을 알려줘.

4. 전문적인 프롬프트

당신은 독일 고등교육 정책 조사자이다. 독일 공립대학의 등록금 정책을 조사하여 한국인 유학생에게 필요한 정보를 정리하라.

다음 절차를 따르라.
1. 먼저 조사 범위를 공립대학, 학부 과정, 일반 학비와 학기 분담금으로 구분한다.
2. 최신의 신뢰할 수 있는 출처를 우선적으로 확인한다.
3. 주별 또는 예외적 등록금 부과 사례가 있는지 확인한다.
4. 출처별 정보가 다를 경우 차이를 명시한다.
5. 최종 결과를 '핵심 요약–세부 설명–유의 사항–출처' 순서로 작성한다.

불확실하거나 확인되지 않은 정보는 추정하지 말고 별도로 표시하라.

5. 비교 분석

초보 프롬프트는 일반 지식이나 최신성이 불명확한 답변을 얻을 수 있음
전문 프롬프트는 조사 절차, 출처 검증, 불확실성 처리를 요구함
ReAct는 정보 검색과 판단이 함께 필요한 과업에 유용함
